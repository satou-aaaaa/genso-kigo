# 元素記号あて

水素・酸素・鉄・金……元素の記号・名前・原子番号・周期表の位置（周期と族）・ふだんの温度での様子・金属かどうか・身近な使い道を当てる1日5問のゲーム。知らなくても遊べます。押すだけ、時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/genso-kigo/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（まちがえても続く・一発で何問当てられるか）、解いた種類が集まる「元素帳」があります。
- 問題は「名前から記号」「記号から名前」「気体・液体・固体」「身近な使い道」「原子番号」「何周期」「何族」「金属かどうか」「同じ族の仲間」「同じ周期の仲間」「番号の順」「次の元素」。正解すると、その元素の札（記号・原子番号・周期と族・様子・使い道）と「なぜ」と出典が出ます。
- 元素は118（周期表のすべて。はじめの45に、2026-11-08 から73を足した）。問題は1142問（13種類。「豆知識から元素」を足した）。正解のあとに、24元素では豆知識も出ます。チケット・回数制限はありません。
- 文字の大きさは3段から選べます。見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）もあります。
- 機種を変えるときは「引き継ぎ」で、記録をコードと QR にして移せます。

## 中身の出どころ

- [文部科学省「一家に1枚 周期表」](https://www.mext.go.jp/stw/series.html)：身近な使い道と身近な話（版ごとの変更点の PDF と概要解説の文を短く言いかえた）
- [日本化学会「原子量表」](https://www.csj.jp/international/atomictable2012.pdf)：元素の日本語の名前（ヨウ素・フッ素・スズなど）
- [IUPAC「Periodic Table of Elements」](https://iupac.org/what-we-do/periodic-table-of-elements/)：周期表の形と、族の番号（1〜18族）
- [理化学研究所「ニホニウム」](https://www.riken.jp/pr/fun/nh/index.html)：113番ニホニウムが日本で初めての新元素であること

ホウ素・ケイ素・ゲルマニウム・ヒ素は、金属とも、そうでないとも言える元素なので「金属かどうか」の問題に出しません。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：画面を開くと文字（Google Fonts）のために Google へつなぐので、文字が端末に保存済みでも Google に IP アドレスが届くことがあります。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（問題と答えは入りません）。
